Dilution-aware forecaster for GTA VI trophy earn rates on Exophase: an earn rate is earners divided by players tracked, and both sides move. The program fits log-time growth of players tracked and of per-trophy earners, projects both to the target, and reports five quantiles per trophy. When the history is flat it falls back on a dilution prior calibrated on the first observed Exophase refresh (players x6.06, earners ex-100% trophy x1.34, so a typical rate fell to x0.22).

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
